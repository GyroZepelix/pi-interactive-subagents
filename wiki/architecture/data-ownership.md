# Data ownership

## Data ownership

- Pi session JSONL files are authoritative for conversation entries and result summaries (`pi-extension/subagents/session.ts`).
- Structurally validated Pi loadout sidecars preserve Pi replay state. Version 2 adds only ordered MCP source identity/digests and support names, never config bodies or credential values. Version 3 (`registry-capabilities`) is written only when a launch has skill files, `inherit-skills: false`, or a registry-scoped MCP reference; it adds canonical skill paths and `inheritSkills`. Separate strict AGY state sidecars preserve the exact conversation ID, runtime/profile identity, cwd, model, effort, logical/native tool mapping, generated primary-agent Markdown, and for version 2 the ordered additional workspace roots (`pi-extension/subagents/mcp-config.ts`, `pi-extension/subagents/agy.ts`, `pi-extension/subagents/session.ts`, `pi-extension/subagents/index.ts`).
- Strict model-chain sidecars contain only controller/profile/runtime identity, current target position, running/exhausted/failed state, and bounded attempt provenance. They are collision and resume-ownership records, not conversation replay or crash-recovery logs (`pi-extension/subagents/model-chain.ts`).
- Activity snapshots are version 1 JSON files written by temp-file rename. `agent_end` is a waiting state that remains writable across retry activity; terminal auto-exit records `latestEvent: "agent_settled"`. Structurally invalid or wrong-child snapshots are rejected. An invalid optional diagnostic string (`toolCallId`, `toolName`, `messageEventType`) is dropped rather than rejecting the snapshot (`pi-extension/subagents/activity.ts`).
- `config.json` is an untracked local override; `config.json.example` is the fallback. The schema accepts `status.enabled` and an optional top-level positive-integer `maxConcurrent`. When set, it rejects a spawn or resume before pane creation once this parent's running plus in-flight launches reach the cap. Steering, model-chain fallback attempts, and orphans of earlier parents are not counted (`.gitignore`, `config.json.example`, `pi-extension/subagents/status.ts`, `pi-extension/subagents/index.ts`).
